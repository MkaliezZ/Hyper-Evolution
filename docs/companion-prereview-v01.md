# AI预审与教师评阅 · v6

把DeepTutor的来源绑定语义评估方式适配进教师人工审阅页，没有引入整个DeepTutor。三层、旧任务、本地网页、本地MCP、配对和自有API保持原有边界；v1—v5契约冻结。只增三张教师私有侧表：`companion_prereviews`、`companion_review_drafts`、`companion_review_publications`。

## 教师使用

1. 在自己的电脑配置API，选择已配对学生，打开收到的作品。
2. 点击“AI预审 / 人工评阅”，核对任务、原答和标准；也可直接人工填写。
3. 点击“生成 / 重新生成AI预审”。候选包含分项观察、原文引用、反馈、下一步和无法判断项。不覆盖正在编辑的内容，不写入正式教师评阅。
4. 点击“采用为可编辑草稿”，逐项修改。“保存本机草稿”不发送；再次打开可继续编辑。
5. 亲自核对后勾选教师确认，另点“确认教师反馈并发送”。整体达标需每项记录支持观察；口语还需真实录音和明确听取确认。
6. 学生收到教师反馈和是否参考AI、是否修改的简要标识。模型原稿、未发布草稿和私有修改历史不发送。

可勾选“收到新的提交时自动准备预审”，默认关闭，消耗教师自己的API。失败或重启不自动重试。关闭后已运行任务可能完成，但不自动发布。网页服务需保持运行；独立stdio MCP不运行后台队列。

## 固定三层

| 层 | 内容 | 边界 |
|---|---|---|
| 审美层 | `learning.teacher_prereview@teacher-prereview-1.0.0`：依实际作品和任务标准，接受有依据的同义表达、核对矛盾、保留未知、给具体下一步 | 专业判断为候选；结构与引文检查不证明教学质量。不套用单一英语题型 |
| 功能层 | v6上下文、Agent、队列、授权复核、草稿版本、人工发布与中断恢复 | 模型只有上下文读取工具，不能签署教师结论；共用Runtime门面 |
| 资产层 | 原答/材料文字范围引用、候选哈希、草稿父版本和修改字段、评价关联与签名发送摘要 | 引用不是凭据；解除配对禁止继续调用；不自动进入共享方法库 |

来源、答案、标准、附件或已有教师评阅变化后，旧候选和草稿失效。草稿使用期望版本，拒绝覆盖新版本。发布绑定草稿版本和哈希；同请求重试不重复评阅。正式评阅落盘而后续审计或发送队列中断时，原请求可恢复。

## 当前覆盖

本轮为文字预审，只发送当前作品、要求、标准、必要参考及帮助声明。排除Key、联系方式、教师私有备注和文件路径；必要上下文会发送至教师配置的模型商，仍属于云端推理。

未自动读取音频、图像或PDF，不自动转写、判定发音、口语流利度、真实听辨或官方分数。附件核对实际字节哈希后标为未读；声音相关维度保留未判定。教师在任务页听取/查看原件后填写观察。客观题继续已有程序核对，不重算历史分数。写作仅预审当前稿；首稿与修订史另查，不宣称独立掌握。

模型候选的引用先逐字检查。一次纠正后仍不能回查的引用会被弃用，该维度降为未判定并保留核对提示；不冒充已核验依据。外部Agent直接提交`review.capture`时，错误引用仍拒收。单次模型任务最多5次请求、总时限6分钟；不会无限重试。

## MCP与验收

`invoke_companion_capability`使用`companion.capability.v6`；完整Schema见`get_companion_architecture.review_extension`。教师作品能力必须显式选择`peer_id`。

| 能力 | 作用 |
|---|---|
| `review.context/list` | 当前授权作品、冻结标准、上下文哈希和私有历史 |
| `review.start/job` | 排队本机API预审、查询；网页服务执行 |
| `review.capture` | 外部Agent使用自己的模型，携带哈希保存候选并复核引文 |
| `review.draft.save/read` | 保存可修改草稿；期望版本防覆盖 |
| `review.publish` | 教师独立确认后写入既有v2评价，签名反馈 |
| `review.settings/settings.save` | 本机自动预审开关，不自动发布 |

无Key、API异常、越权、解除配对、伪造引用、缺项、版本变化或证据不足均不自动生成正式结论。Agent不能冒用教师确认或声称听过录音；设备声明不认证真实身份/资质。

验证：`test_companion_prereview.py`、完整回归及`scripts/verify_companion_prereview.py`的真实HTTP、stdio/HTTP MCP。合成工程测试与真实API连通不代替专业审定及真人学习效果，后两项由用户另行安排。DeepTutor来源、改动和Apache许可见`third_party/deeptutor/`。
