## 六对象与三层

| 对象 | 工程含义 | 所在位置 |
|---|---|---|
| Scenario 场景 | 谁遇到什么问题、目标、条件、责任与预期结果 | 请求和活动上下文；不新增第四层 |
| Module 模块 | 可维护的职责边界 | 功能层，不要求独立部署 |
| Capability 能力 | 接受什么、返回什么、质量与失败约定 | 功能层对外接口 |
| Agent / Skill / Workflow | 内部执行方式；也可用普通代码和人工 | 功能层内部实现 |
| Policy Pack 规则包 | 专业判断、选择理由、约束、正反例和验收 | 审美层；不是界面配色或仅安全校验 |
| Asset 资产 | 内容、个人记录、方法、证据及其治理 | 资产层；规则文件可以作为方法资产保存 |

新代码放在 `src/base/app/companion/`：

- `aesthetic/`：判断与证据要求。不得导入功能层、数据库、网络、模型 SDK 或传输实现。
- `assets/`：引用、版本、定位和完整性。不得导入审美层、功能层、Runtime 或传输实现。
- `functional/`：公开契约、授权投影和编排，可依赖前两层。Harness 属于本层，选择规则、装配上下文、执行、检查、如实返回状态。
- `LocalRuntime.invoke_capability` 是接入现有产品的门面。HTML HTTP、MCP、内置 Agent 都通过它读取新能力；传输层不得复制证据选择与权限逻辑。

既有 BASE、英语业务、师生传输和本地存储本轮不搬迁。新模块对旧记录做适配，不因目录重命名而重写整个产品。跨层依赖由 `tests/test_companion_architecture.py` 检查；它只验证结构边界，不能证明专业规则正确或学习有效。

## 判断责任与执行边界

保留 P01—P10 和 M01—M06。专项训练母本只是 M03；修辞目的题用连线只是一个场景，其他学习可直接讲解、探究、应用或复盘。

第一阶段运行的 `learning.evidence_boundary@1.0.0` 只覆盖当前授权、来源绑定、未知状态、评价来源和不自动推断掌握五项边界。完整十个专业包仍为候选设计，尚未经领域审定。不得把此子集称为完整审美引擎。

实际权限由可信代码核验；语义判断可由 Agent、工具、教师或其他专业人员执行。模型输出不是保存事务、教师签名或正式达标。学习者正常合作与额外帮助应由场景定义，旧记录缺少这些条件时标为未记录，不能反填“独立完成”。

## 资产与历史

引用包含资产 ID、任务 ID、主体、版本、内容 SHA256 和定位。引用不是访问凭据。每次解析先核验当前角色 / 配对和任务，再检查引用版本，最后才读取相应载荷。

原件、解析、索引、学习产出、评价和摘要分开。处理状态、领域审核、本次适配和权限是独立维度。本阶段提供当前授权快照的引用与文字范围定位；页码、图区和媒体时间有结构校验，但无对应读取适配时返回 unavailable，不虚构 PDF、OCR 或音频切片能力。

旧数据库不迁移，旧任务不补造规则版本、帮助、场景或维度证据。自身任务证据读取已存评价，不调用当前算法重算历史。评价引用会随当前评价变化而失效；历史 review 引用仍可定位保留的旧评阅。不承诺完整冻结历史 Python 代码。

## 数据流与回流

场景 → 审美层选择标准 / 方法 / 材料 / 证据条件 → 功能层验证授权并执行 → 资产层保存或读取可追溯内容。个人回流服务本人；共享方法回流须另有用途依据、筛选、脱敏、专业审阅及负责人发布，本阶段尚未建设自动发布路径。

保留本地网页、本地 MCP、用户自有 API 与配对交换。授权交换产生双方副本；解除配对保留副本，但新证据能力不再把已解除关系的任务纳入当前上下文。云模型收到必要上下文不等于离线推理。

## 顺序与版本管理

第一阶段先验证统一证据、契约和引用；通过后才推进阅读交互、新评价账本和预览导入。第一阶段不会把 DeepTutor 引入运行依赖，不会部署或替换公开下载包。新增能力需维护同一公开契约、角色边界、历史兼容和两入口一致性。

公开请求与结果的 JSON Schema 固定在 `docs/contracts/companion.capability.v1.*.schema.json`，运行时也可通过 architecture.describe 读取。测试确保声明与代码一致；破坏兼容的字段或语义改动必须提升契约版本并保留旧契约适配，不能只修改快照让测试通过。
