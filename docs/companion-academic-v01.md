# 学科入口与 K12 教学链 v0.1

0.5.0 工程扩展；固定三层架构和旧 v1—v6，新增 `companion.capability.v7`。真实师生试用由用户另行安排。教师经营（咨询CRM、试听、课包、排课、招生）不纳入本轮。

## 场景与六对象

场景是学生在明确教材单元或考点上遇到困难，教师需要准备可核对的练习、保留原答、检验可能原因，再安排有效验证。它不要求先建立完整诊断档案。

| 对象 | 本次实现 |
|---|---|
| Scenario | 所选学生、英语/K12、学段年级、课程/考试路线、明确目标与当前单元顺序 |
| Module | 学科学习与K12教学模块；与留学英语及教师经营分开 |
| Capability | v7 的路线、范围、草稿审题、库存、问题证据、评分讲解、报告与班级能力 |
| Agent / Skill / Workflow | 可替换的模型生成/独立审题适配器，普通代码检查、人工审题、签名配对工作流 |
| Policy Pack | `learning.k12_teaching@1.0.0`，条件、操作理由、证据要求、失败和未知处理；专业状态 NOT_REVIEWED |
| Asset | 原始材料/录音、版本范围、候选题、审题声明、冻结活动、原答、问题假设、评分、勘误与反馈 |

## 三层调用和回流

```
本机 HTML / 外部 Agent MCP / 内置模型任务
                ↓ 同一个 LocalRuntime.invoke_capability
功能层 academic.py：鉴权、当前学生、范围和指纹、事务重放、编排
       ↙                         ↘
审美层 academic.py              资产层 academic.py
范围适配/逐选项审题/证据门槛     内容指纹、冻结引用、完整性、公有投影
目标测验/未知处理/下一步选择       原件不改写，历史可回查
       ↘                         ↙
功能层持久化 Harness → 本机侧表 / BASE任务 / 配对签名消息
                ↓
学生原答 → 自动错法线索 → 教师补充证据、可修正原因假设
                ↓
学生短解释 + 教师私有讲稿 → 未见题验证 → 路线范围内报告
```

功能层可以依赖规则和引用；两个下层不能导入功能层、Runtime、数据库、网络或模型。模型 SDK 只存在功能层适配器。原 BASE core 未修改；新增一张追加式 `companion_academic_records` 侧表，旧数据、网页、本地MCP、自有API和配对保留。

## 可用教学链

1. 学科与学习路线分别选择。英语包含K12、留学英语、资料学习；数学、科学、人文、其他学科暂以通用资料学习进入，不宣称已有对应领域完整测评。旧留学档案和记录不被重新标记。
2. 每位学生可建多条小学/初中/高中课程或考试路线，1—12年级，独立目标、日期和明确单元进度。范围按教材、单元、顺序、词表、短语、语法、来源和原始资料引用版本保存；超过登记进度的范围拒绝出题。
3. 无API可手工编写、使用原创示例、预览导入JSON草稿。有API时用自然语言生成1—10题候选；读取实际路线和范围，存草稿，不自动发布。支持13类内容：语法选择、完形、阅读选择、听力、信息匹配、阅读表达、写作、写作任务、判断、补全对话、连词成句、选句填空、语法填空。单个空/匹配项按一题保存，复杂题组按若干题拆开；本版作答使用选择或文字输入，不提供拖拽连线、完整考试模考或全国题型分数换算。
4. 独立审题模型先读取不含答案的题目，保存独立作答，再读取参考答案，逐题逐选项给出候选依据、误读路径、排除理由和小练习。分歧保留；教师须修题或写具体处置理由，实际逐题核对后独立确认。内容变化使旧审题失效。生成模型的自评不能代替独立审题或教师确认。
5. 听力须导入有权使用的WAV/MP3原件，最多12MB，保存来源及真人来源声明，教师实际完整试听。哈希只证明字节配套，不认证真人或音质；模型没有自动听过音频。学生交卷前不显示听力原文。
6. 已审、未停用且当前范围有效的题目入库存；按考点/范围选取，排除该学生已布置见过的题目。记录缺口；组题须题量足够，重组后重新审校。范围更新、停用或已见使旧选择失效；不自动缩减题量、不在后台无限补库。
7. 公开任务冻结规则版本、题目指纹、范围和帮助条件。客观题按接受答案核对；开放回答保持待评、不算零分。原答及原始自动成绩保留，主观评分、解释和勘误另存版本。
8. 错项干扰类型、真实错法、原因假设和验证证据分开。选择某干扰项不能自动确认原因。确认需要教师观察、学生实际原话或另一份实际检查作答，并保留证据来源和教师声明。补充追问不改原成绩。
9. 教师可记录双版本讲解，学生只收到简短解释和下一步；教师讲稿及证据私注留在教师本机。K12写作提供内容、交际效果、组织、语言四维0—3试行量规，折算原题分值；不是托福/雅思或官方考试评分。
10. 目标测验须施测前确认目标—题号覆盖、独立条件及本次阈值。带提示练习不能算独立测验；未说明帮助、未评题、无效题保持待核对。达到本次自定参考线不意味着长期掌握。目标测验追加原答被拒绝；新测另用新题。
11. 路线报告聚合当前范围内任务、未评、问题证据、测验覆盖和库存缺口。下一步优先坏题和待评，再验证原因、针对困难练习和新情境应用。页面提供按建议准备新候选，仍须审题和确认布置，不自动改教师安排。未记录原因不伪造作答过程。
12. 提交通知和已读分开；连接MCP不等于唤醒外部Agent。班级布置冻结名单并逐人核对，失败可原请求重试，成功项不重复布置；跨学生教材范围需各自映射，条件不足明确失败。报告不把未交/待评计零分。同组候选仅接受相同冻结题目、目标与范围且帮助声明完整的记录，不按学校或粗分数自动分组。

`academic.catalog/context/select`；`route.save/list/read`；`scope.save/list/read/check`；`k12.draft.save/read/list/candidate_review/review/publish/self_practice`；`k12.target.confirm`；`k12.bank.list/pick/compose/retire`；`k12.replenishment.list`；`k12.problem.list/record`；`k12.explain.save`；`k12.score.record`；`k12.evidence.correct`；`k12.report/next`；`k12.notifications[.read]`；`k12.class.save/list/assign/report/candidates`；`k12.media.save/read`；`k12.import.preview/commit`。

请求通过 v7 统一门面。`architecture.describe` 返回模型Schema和逐操作载荷Schema。修改使用 expected_revision；重放同请求必须同内容；操作前及读取缓存后重查当前配对。撤销配对不删除对方既有副本。加密恢复包含新侧表和原录音。

模型生成/独立审题仅调用当前设备自己配置的API，不将教师私注或密钥放入模型上下文；必要的练习文字会发送到用户选择的模型服务商。本机优先不等于离线推理。

## 对照报告边界

本轮补的是K12教学流程，不复制云端账户、免安装手机作答链接或后台经营系统；不宣称涵盖对方全部功能。学段目录和考点是工程候选，未分发完整官方课标词表、各版本教材、第三方题库或真人录音。词表检查只核对实际输入的表面词形，未匹配词须人工核对；词表不完整时返回未知，不直接判超纲。

界面导航按“学习领域 → 学科与路线 → K12英语学习/教学”分层；子学科入口不作为独立的一级领域。科研、项目等未来领域可在“学习领域”下另行接入，不强制套入学科分类；本轮不添加尚未实现的占位入口。三层工程说明保留在架构文档，不放在日常学科选择页面。

学科选择页采用“学科列表 + 当前学科路线”的两区布局，小屏改为上下排列。点选学科只切换预览，不写入当前学习选择；点击具体路线入口后，才通过原有能力切换到对应空间。路线卡分别展示适用人群、用途与明确入口，资料学习入口保留当前学科支持范围说明。

## 学科资料归属修正

学科入口原先只保存当前选择，通用资料页仍读总库，导致数学、英语等入口显示相同资料。本修正将文字及原图的学科归属存入追加式 `asset_subject` 记录，按实际资产ID、版本和内容哈希绑定；原始资料、任务快照和旧反馈不改写。新增v7能力 `academic.material.list/save`、`academic.page.save`、`academic.asset.info/classify`，v1—v7现有请求/结果Schema及旧操作载荷不变。

新页面仅展示明确归入当前学科的资料，新保存内容必须声明学科。已有资料及通过旧v2/v3接口写入的内容保留在“待分类”，不根据语言或标题自动猜测；用户查看资料后明确确认归属。通过旧接口修改原文导致绑定版本不符时，移入待重新分类视图；旧归属记录仍保留。分类调整只移动当前列表归属，不修改原文或追改历史任务。各学科原创示例分别提供，不能用一个英语示例冒充所有学科内容。

分类是本人本机的组织视图，不是不同用户的权限边界或学科专业审核。旧版全库API保留兼容；外部Agent应使用带显式subject的v7能力。配对方不能读取本机个人资料库。跨学科检索工具明确标注为全库范围，其索引与历史对照不随页面切换而改写。已绑定的K12历史来源继续可回查，新范围选择器优先列出英语资料。

验收：`tests/test_subject_materials.py` 检查文字/原图筛选、旧资料不猜归属、来源变化、分类CAS、失败重放、签名历史保留、HTTP/MCP一致和加密恢复；`scripts/verify_academic.py --report-tag subjects` 验证真实HTTP、独立stdio及HTTP MCP，输出单独证据，保留旧发布报告。此修正未重新发布官网冻结包。

当前验证以源码回归、真实HTTP/两种MCP传输、实际自有模型候选、签名师生交换和新冻结程序为工程证据。真实教师/学生试用、学科审定、量规校准和学习效果仍需另外验收。
