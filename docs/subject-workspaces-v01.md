# 独立学科工作区（源码工程版）

本次以“选定学科后进入独立工作区”为边界。此前“全部资料＋学科筛选”的菜单方案被替换。URL 参数不能跨学科读取，资料分类也不再代替工作区切换。

## 使用路径

1. 打开“学科与路线”，点选学科查看路线，再点击进入。仅浏览选项不改变当前工作区。
2. 当前学科在顶部显示；资料、作业、提交、反馈、档案备注、札记、复习、索引、安排、写作和模型任务均来自该学科数据库。
3. 从资料库的“切换学科”或顶部入口返回选择页。英语 K12 和留学路线仅在英语工作区显示。
4. “添加学科”建立新目录和空数据库，使用通用资料学习；不会自动产生专业学科规则、考试题型或校准量规。
5. 同一老师/学生身份、配对连接和用户自己的模型配置共用；各学科的教学内容和学习记录独立。

## 磁盘结构

```text
本机数据根目录/
  base.sqlite3                  # 设备配置、配对以及完整旧版历史
  device.json                   # 共用设备公钥身份，无明文私钥
  subjects/
    english/
      workspace.json            # 学科 ID、名称及所属设备
      base.sqlite3              # 本学科教学与学习记录
      materials/<asset-id>/
        v1.txt                  # 文字原件
        v1.json                 # 来源、哈希、版本元数据
      uploads/                  # 原图与学生作品附件
      media/                    # 本学科题包音频
      peer-media/               # 收到的任务音频
    mathematics/
    science/
    humanities/
    other/
    subject-<稳定标识>/          # 用户新建学科，名称记在 workspace.json
```

数据库和文字文件逐版本核对。手动改写已保存 TXT 不会悄悄改变原件；需在页面保存修订，或恢复原文件。目录名不接受用户路径，包含越界校验；目录说明与设备、学科登记须一致。

## 三层职责及接入

- 审美层继续负责通用判断方法及专业规则，学习情境列表与实际执行均核对学科适用边界。学科隔离不代表数学等专业教学能力已经审定；非英语通用建议不采用托福、雅思或 K12 英语蓝图。
- 功能层 `workspaces` 装配当前数据库、共享身份、请求上下文、事务及签名投递；`workspace_lock` 协调网页和独立 MCP 进程。学科 Runtime 由既有 LocalRuntime 工厂提供，功能层不反向导入 Runtime。
- 资产层 `workspaces` 只负责目录标识、原件定位和完整性。各学科沿用已有三层能力与表，不改 BASE core。

新增 `companion.capability.v8`：`workspace.initialize/list/select/create/legacy.import`。请求/结果快照在 `docs/contracts/companion.capability.v8.*.schema.json`。v1—v7请求/结果结构保留；启用工作区后，所有公开调用均解析为当前学科，v7学科选择作兼容适配。旧版未启用实例仍可按原流程使用。

网页、HTTP MCP 和 stdio MCP 共用门面。Agent 先读 `workspace.list`，明确调用 `workspace.select` 后再操作旧学习能力。MCP 配置始终指向数据根目录，不能把某个子目录当成另一份设备安装。HTTP 会话及 bearer 凭据在切换学科后保持有效；请求和模型后台任务固定本次学科，不随中途切换串库。旧网页的学科标记与当前工作区不一致时拒绝读写，要求刷新。

## 师生连接

双方须使用支持分学科协议的版本并初始化工作区；握手未确认支持的旧设备不会收到新学科任务。学科标识和名称属于被签名的消息载荷。收到任务时按学科投递到对应目录，不替学生切换当前学科；提交和反馈沿同一学科返回。身份、签名、角色、配对撤销和原图/音频校验继续生效。

标准学科 ID 两端一致。老师创建的自定义学科随合法任务在学生侧建立对应目录；若学生已有同名但不同 ID 的个人学科，老师任务工作区单独标注，不按名称擅自合并。两个同名自定义学科的手动合并尚未实现。

## 原有数据处理

- 旧数据库和文件原样保留，不删除、不重写旧签名、成绩或评阅。
- 有有效人工分类、且与真实版本/哈希对应的文字与原图，复制所有版本到对应学科。未分类或源版本失效的资料留在独立“历史工作区（待归属）”。
- 已有、带托福/雅思类型的英语题包复制到英语库，配套音频重验哈希后迁入；失效音频及冲突题包留在旧库，并记录迁移问题，不阻断其他学科初始化。
- 历史作业、原始提交及相关副表保留在只读历史工作区。本轮没有猜测、自动拆分或搬迁这些历史任务；活动化继续学习需在目标学科建立新任务。历史任务整组迁移尚未实现。
- 历史资料可明确确认后迁入指定学科，旧原件仍保留。重复确认受操作指纹、源版本及内容冲突检查保护。
- 加密恢复包包含旧库和全部已登记学科的数据库、文字、原图、作品与音频；恢复前逐库校验身份、文件哈希及路径，更新本机绝对路径。

## 验证及交付边界

运行 `tests/test_workspaces.py`、架构/旧能力相关回归、`tests/navigation.test.cjs` 与 `scripts/check.py`。真实 HTTP、独立 stdio MCP 和 HTTP MCP 验证见 `scripts/verify_workspaces.py`，结果写入新的 `artifacts/workspaces-transport-verification.json`，不覆盖历史发布验收。

本次是源码和本机预览更新；公开 0.5.0 安装包没有重打包或重新部署。工程验证不代表真实师生试用或新学科教学效果通过。
