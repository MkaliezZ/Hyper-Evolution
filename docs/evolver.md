# Evolver · 学生版

你的日常入口只有四组：学习首页、我的任务、反馈与修订、目标与安排。

## 第一次和老师连接

1. 解压学生包，双击 `启动-Evolver.cmd`，确认学生身份并填写称呼。
2. 打开“连接与设置 → 我的老师”，输入老师发来的十二位配对码。双方保持程序在线，等待显示已连接。
3. 选中本次任务所属的学科，打开“我的任务”，阅读要求和评价标准。
4. 完成练习、写作或录音作品，检查后点击提交。作品会发送给已配对的老师。
5. 到“反馈与修订”查看老师发来的建议，完成修订后再次提交。
6. 到“目标与安排”查看老师分享的规划和学习安排，按下一步继续。

## 什么时候需要配置 API

完成任务、提交作品和查看教师反馈使用本机工作台。任务中的资料解释或写作 AI 帮助使用你自己配置的 API；在“连接与设置 → 模型与本机设置”填写即可。老师的 AI 预审由老师自己的模型账户承担。

外部 Agent 可以使用自己的模型，通过本地 MCP 读取允许访问的任务并执行相应操作，见 [MCP 教程](mcp.md)。

## 学习记录放在哪里

记录保存在本机。提交给老师后，老师的电脑也会保存该次作品。换电脑前，在设置中创建加密恢复包。

想独立学一份自己的资料，可以明确切换到 Self-Evolver；老师布置的任务继续从学生版完成。

逐项操作见工作台“使用指南”或[完整学生说明](usage/student.txt)。
