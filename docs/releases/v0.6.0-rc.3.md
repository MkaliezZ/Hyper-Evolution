# v0.6.0-rc.3 · 自学反馈引用保存修复

日期：2026-11-08。Enlighter、Evolver、Self-Evolver 三个 Windows 工程测试包同步更新。

## 这次改了什么

当 AI 返回多条有效引用时，旧实现会把它们用分号拼成一条。例如原稿是 `A garden offers shade.`，模型分别引用 `A garden` 和 `offers shade.`；拼接后的一句话在原稿中找不到，反馈就停在保存步骤。

现在，评价记录的单段引用字段保存第一条逐字引用，完整引用清单保留在模型任务结果中。自学者可以顺畅接着查看建议、修订作品、记录反思和安排复习。

审美层继续逐字核对每条引用；功能层只修正结果到评价记录的投影；资产层继续保存原稿、模型输出和每次评价。三层架构、v1—v11 能力契约、MCP、师生配对及用户数据目录沿用原有设计。

## 怎么更新

1. 打开旧版的“连接与设置 → 模型与本机设置”，点“保存并退出服务”。关闭网页后，后台服务仍可能运行，因此请完成这一步再换新版。
2. 从官网或 GitHub Release 下载对应的 rc.3 工程测试包，完整解压到新的程序文件夹。
3. 双击对应启动文件。首次启动保持联网，等待运行环境准备完成；新版继续读取原有的默认用户数据目录。自定义数据目录的用户继续使用原来的 `--data` 参数。
4. 打开原任务，重新发起“用我的API准备作品反馈”。原来的首稿、修订、配对与 API 设置继续保留。

教师和学生也请下载各自的 rc.3 包，保持三个入口版本一致。历史安装包继续保留供回看和回退。
