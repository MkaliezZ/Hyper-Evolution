## 固定三层，如何实际调用

| 层 | 本批实现 | 验收边界 |
|---|---|---|
| 审美层 | `aesthetic/packs/P01—P10` 候选判断规则；M03 专项母本；`engine.py` 装配六类方法和八种起始情境，形成实际决定、理由、缺项、失败处理和规则哈希 | 每包选择相关运行条件；不宣称所有专业规则都可自动判真。修辞连线仅为该情境的候选形式，写作、听辨、口语、数学、调试使用不同操作。专业审阅仍为 NOT_REVIEWED |
| 功能层 | `continuity.py` 统一 v3 Harness；现有文字解释和学习建议也装入规则上下文；新增原图模型适配；现有逐项评价调用冻结规则检查 | 授权先于读取；缺声音不能发布听辨活动；专项缺操作、问题、标准不能发布；形式改变须说明理由；独立性冲突和长期掌握/官方等级过度结论被阻止 |
| 资产层 | 原图字节校验、不可变版本、来源及图区引用；作品和反馈引用；札记版本及复习事件 | 原件和模型观察分离，札记不是事实认证；输入、衍生记录和正式判断保留来源。个人回流不会自动发布公共方法 |

典型调用：`page.save / material.save → policy.plan → activity.create → 原有 submit_work → assessment.record → memory.capture → review.create / record`。网页、本地 stdio MCP、受保护 HTTP MCP 使用同一 Runtime 门面；MCP 的 `read_original_page` 返回实际 ImageContent，而不只返回路径。

规则计划冻结目标、困难假设、关键操作、形式理由、正常工具/本人责任、评价标准、下一步验证、规则文件版本和 SHA256。预览因条件不足或冲突而失败时不创建活动。旧任务不补造规则或帮助条件。v2 新活动也绑定运行规则，旧反馈接口不能绕过逐项证据直接确认新任务达标。

六类方法为理解、探究、针对困难练习、应用、复习、复盘。M03 不统辖其他五类。初始情境和量规是可调整候选，不能据此声称已覆盖全部学科。

## 原图

支持单页 PNG/JPEG，2MiB、1200万像素、8000像素边长以内；验证解码后仍保存原始字节。原图不经过模型重绘、OCR或转写替换。模型读取时发送整图及所选关注范围；区域采用显示方向归一化坐标，非原始文件字节中的像素坐标。

教师仅发送当前活动绑定原图；源资料以后修订不改变已布置快照。每次读取、模型调用后保存结果、MCP 图片返回都重查配对和版本。实际 HTTP 图片仍受既有身份、Origin/Host 和访问保护。上传通用能力接口上限为3MiB，原图实际字节另限2MiB。

原图模型在用户设置中独立填写名称，与主模型共用自有服务地址和 Key；未配视觉模型时仍可查看、布置原图，但不伪装成已由模型读取。支持图片的自定义接口是否兼容须实际验证；DeepSeek 本次工程样例用 `deepseek-flash`。模型图区通过格式及范围检查，不等于模型内容正确或具备专业 OCR 精度。

不支持多页 PDF、自动 OCR、任意表格结构化、音频时间切片。听力沿用已审核题包和录音；在新设计器里可以检查听辨条件，不允许复制成丢失音频的新活动。

## 学习札记

从至多5份已提交作品形成最多3000字的有界摘录，包含可见反馈和帮助声明，排除教师私注。引用绑定任务、提交、原答、反馈和来源哈希。模型最多采用3条当前有效札记，每条1200字，并再次检查当前授权。

原答、最新提交或反馈变化时旧札记标记待刷新，不再自动进入模型上下文；用户可重新从原任务保存札记。手动修订保留历史，默认不供模型采用，需要本人显式勾选。暂不使用可恢复。教师札记按所选学生隔离；不会自动把师生各自札记同步到对方。

这不是全历史检索、向量记忆或已验证的学习者画像。已解除配对的材料不再纳入当前证据，但无法远程删除对方已收到的副本。

## 个人复习

学生从已提交任务建立一张个人复习卡，选择间隔（默认1/3/7/14天）。先回忆或再用，再核对原答；本人声明“想不起来/费力/可回忆”及额外帮助。规则只调整下次日期：again 回到短间隔，hard 缩短，good 进入下一档；额外帮助未明确排除时本次间隔至多2天。完整事件解释参数与来源，不写入教师达标或能力掌握。

可改期、暂停和恢复，原任务暂停/归档时不可新增复习尝试；解除授权后不再列出。无系统后台提醒或离线推送，也未证明所选间隔最优。需教师评阅的复习成果仍在原任务提交，个人回忆记录不自动代交。
