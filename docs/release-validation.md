# v0.6.0-rc.1 工程测试记录

日期：2026-11-03。产品：Hyper Evolution / 超维成长。平台：Windows x64。

## 发布范围

一个公开主仓库，三个在线安装工程包：Enlighter、Evolver、Self-Evolver。共同使用审美层、功能层、资产层，沿用本地网页、MCP、学科工作区和师生配对。首次启动准备运行环境，三版本默认使用不同数据目录。

## 源码与授权整理

- 从经过检查的源码白名单创建独立公开历史，原开发私库继续保留。
- 排除学习数据库、设备口令、模型密钥、真实学习者信息、私有资料、部署记录和历史截图。
- Gitleaks 8.30.1 检查原开发历史及公开源码，报告为零命中；扫描工具的官方分发 SHA256 已核验。
- 保留伴学 BASE 的 MIT 许可，以及 DeepTutor 的出处、适配说明和 Apache-2.0 许可。
- 整理 71 项锁定运行依赖清单。首批 ZIP 采用源码在线安装方式，第三方二进制由安装程序从上游获取。
- 教材、题库和音频继续按各自授权导入；公开包使用原创工程示例。
