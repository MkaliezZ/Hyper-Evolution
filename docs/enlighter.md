# Enlighter · 教师版

先把一位学生、一个目标和一个任务连起来，熟悉后再扩展。

## 第一次带学生学习

1. 解压教师包，双击 `启动-Enlighter.cmd`，按向导确认教师身份。
2. 在“连接与设置”配置自己的模型 API。页面里的 AI 备题与预审使用教师自己的额度。
3. 在“连接与设置 → 师生连接”生成配对码，发给学生。请双方保持程序在线；配对码有效期为十分钟。
4. 打开“学生与目标”，查看已连接学生，从“成长与目标”梳理现状、方向、目标要求和行动。完成后明确分享，学生就能看到这份规划。
5. 进入“备课与任务”，选择当前学科，准备材料、练习目标和评价标准，审校后布置给学生。
6. 学生提交后，进入“作业与反馈”查看原题、实际作品和历次提交。需要时运行 AI 预审，逐项修改建议，再确认发布给学生。
7. 学生修订后查看变化，安排下一次练习或复测。资料、作品、反馈与规则版本会接着保存。

## AI 在哪里帮忙

| 入口 | 用途 | 教师接下来做什么 |
| --- | --- | --- |
| 教学助手 / 备课与任务 | 根据学生情况和资料准备练习草稿 | 检查题意、答案、难度和来源，再布置 |
| 资料阅读 | 解释选段、结合原图提问 | 核对原文，决定如何用于教学 |
| 作业评阅 | 对实际提交生成预审建议 | 编辑草稿，确认后发布 |
| 写作与修订 | 提出修改建议，保留不同稿件 | 根据教学目标选择帮助程度 |

AI 建议、教师草稿与已发布反馈分别保存。页面提交与分享都有明确操作。

## 怎样找到功能

左侧五组入口依次是：教学首页、学生与目标、备课与任务、作业与反馈、教学方法。“学科与路线”切换当前工作区；“连接与设置”里有模型、配对、备份、MCP 和使用指南。

更细的逐项说明见工作台“使用指南”或[完整教师说明](usage/teacher.txt)。外部 Agent 连接步骤见 [MCP](mcp.md) 和 [教师 Agent 操作规范](usage/teacher-agent.md)。
