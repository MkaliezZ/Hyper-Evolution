# S1：资料、活动设计、评价与题库导入

2026-10-28。三层职责继续遵守 `architecture.md`。本批在已有本地产品中新增学习流程，不搬迁 BASE、不改变配对协议、不引入 DeepTutor 运行依赖。

## 普通用户怎样使用

首页「从资料开始」或顶部「资料与练习」进入本机资料库。粘贴资料或从 TXT / Markdown 填入，填写来源；也可使用明确标记的原创示例。

打开资料后，可以选取片段。理解、针对困难练习、应用表达是不同起始方式，不强制先诊断或做五道选择题。理解与应用提供可检查的起始标准；针对训练必须明确困难假设、要练的操作、具体问题和完成标准，不能仅凭一个困难标签就宣称完成专业设计。

任务发布时固定资料片段、来源版本、目标、方法理由、本人责任、评价标准和规则版本。后续修改资料会新增版本，不改变旧任务。教师布置时只发送所选内容，原始资料库不自动共享。

学习者提交作品时可说明正常参与和额外帮助，声明标为本人自报；未填写不等于独立完成。作品修订继续用原有提交历史，不覆盖首稿。

评价账本分本人反思、模型建议与教师评阅。每次记录保留原答哈希、来源、规则与条件；教师确认达标必须亲自审阅并逐项记录支持观察。原句引用必须能在原答或本次资料中找到。教师正式评阅随现有签名任务更新同步；本人反思保留在本人设备。旧反馈仍保留，不伪造为新账本记录。

老师在「题库与试听」选择「表格题库导入」，上传 CSV / JSON，先预览错误和重复，再确认保存待审。页面提供 CSV 示例。字段、选项及答案要按模板整理；暂不解析任意排版的题册。源于社区、个人购买等材料也必须填明来源，来源声明不被当作官方核验。重复导入跳过已有内容，不撤销旧审核或覆盖旧题。

## 模型与来源引用

「问一问所选原文」调用用户在本机配置的 API，服务端重新读取授权版本；客户端不能直接提交假原文让模型当作来源。模型必须实际读取资料工具。返回的每条引文须在所选文本中逐字匹配，并记录版本及文字位置；这只验证引用匹配，不证明解释语义正确。

解释不自动评分、发布教师判断或更新掌握。来源来自教师任务时，模型工具读取及返回前重新核对配对；密钥不进入 SQLite，不使用平台 Key 作为默认回退。

## 架构落点

| 层 | 文件 | 职责 |
|---|---|---|
| 审美 | `aesthetic/scenarios.py` | 三类方法的目标操作、选择理由、标准、正反例与未知行为；都是待专业审阅的候选 |
| 功能 | `functional/study.py`、`study_contracts.py` | 请求校验、当前授权、教学装配、版本读取、发布与评价 |
| 功能 | `functional/reading_agent.py`、`bank_import.py` | 可替换的来源解释与有界导入实现 |
| 功能 | `functional/study_store.py` | 调用现有本地数据库，保存版本、预览、追加评价和重试回执 |
| 资产 | 原引用模块 + 版本化资料载荷 | 稳定 ID、哈希、版本、选段位置；旧任务资产引用继续有效 |

Harness 仍在功能层；不是每项能力一个 Agent。审美层不访问数据库或模型，资产层不反向依赖执行。十个完整专业 Policy Pack、其他方法母本及跨学科专业评价没有被本批替代或宣布完成。

## 网页与 MCP 共用 v2 契约

保留 `companion.capability.v1` 及其 Schema。通过原 `POST /api/local/capabilities/invoke` 或 MCP `invoke_companion_capability` 传入：

```json
{"contract_version":"companion.capability.v2","request_id":"unique-operation-id","operation":"study.options","payload":{}}
```

操作：`study.options`、`material.list/save/read`、`activity.create`、`assessment.list/record`、`bank.preview/commit`。老师布置或查看学生作品时传已配对 `peer_id`。读取 `get_companion_architecture` 可取得请求、结果和各动作载荷的 Schema。

写入动作需稳定 request_id，内容变化使用新标识；请求指纹冲突拒绝。发布、反馈沿用 BASE 幂等，准备内容和回执本机保存，可恢复未完成的回执写入。授权先于重试回执读取，旧引用不绕过解除配对。

首次使用 v2 时仅新增四张 `companion_*` 表，不回写旧学习记录；普通备份仍包含整个 SQLite。升级前按原流程退出服务并保存加密恢复包。旧程序不知道新表，不能用旧程序伪称可编辑新功能；未实施自动跨版本降级。

## 验收与已知范围

- 单元与回归：`python -m pytest tests -q`，包括原 BASE、权限、模型、备份与新增正反例。
- 真实 HTTP / stdio MCP / HTTP MCP 与浏览器：`scripts/verify_companion_foundation.py --study --browser-node <Node路径>`，Node 需可解析 Playwright；全部合成数据。
- 自有模型实际调用：`scripts/verify_study_model.py --env-file <明确授权的私有配置>`；自愿执行且由该模型账户计费。密钥不打印或分发。

本批支持文本 / TXT / Markdown、CSV 与 JSON；PDF/OCR、XLSX、原图图表、复习调度、完整长期记忆留在后续批次。听力题继续使用已有 ZIP、音频哈希与人工试听流程，不把 TTS 替代真人题材。

技术通过与引用匹配不等于教师专业审定或真实学习效果。代码、公开安装包、服务器是不同交付状态，本批默认只更新源码和本地预览。
