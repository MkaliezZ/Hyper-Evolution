# 安装、API 配置与第一次使用

## 1. 下载与打开

在 [Releases](https://github.com/MkaliezZ/Hyper-Evolution/releases) 下载教师版、学生版或自学版的 Windows x64 工程测试包，完整解压。双击包内对应的“启动”文件，本机浏览器会打开设置向导。首次启动需要联网，向导会自动准备 Python 与依赖。后续启动直接使用已安装的本机环境。

首次启动时确认身份、填写称呼，选择学科与路线。教师端选择 Enlighter；跟随老师的学生选择 Evolver；独立学习选择 Self-Evolver。向导会预选本包对应的入口。

当前工程包采用源码与一键在线启动脚本组成的 ZIP 分发。首次打开时 Windows 可能询问文件来源；可先核对 Release 中的 SHA256 文件和包内版本清单。

## 2. 连接自己的模型

打开“连接与设置 → 模型与本机设置”。准备模型服务商提供的四项信息：服务商、接口地址、模型名称、API Key。输入服务商文档给出的模型名；OpenAI 兼容服务通常填写以 `/v1` 结尾的接口地址，DeepSeek 预设使用 `https://api.deepseek.com`。

先点击“测试连接”，成功后保存。测试和后续 AI 请求都由该 Key 对应的账户计费。选择记住后，Key 保存在系统凭据管理器；也可以选择本次使用。

网页中的资料解释、备题、写作建议、自学反馈和教师 AI 预审使用这里的配置。查看任务、提交作品、人工反馈和整理资料使用本机能力；外部 Agent 的模型额度由该 Agent 自己管理。

## 3. 做一件小事

- 教师：打开“学生与目标”，连接一位学生；从“备课与任务”准备一个短任务。
- 学生：打开“我的老师”输入老师的配对码，再到“我的任务”完成并提交。
- 自学者：导入一段自己的短资料，阅读后用一个理由回答一个问题，再查看反馈并修订。

完整操作：[教师版](enlighter.md) · [学生版](evolver.md) · [自学版](self-evolver.md)。

## 4. 保存、退出与升级

关闭浏览器页面后，本机服务会继续运行。准备退出或升级时，在设置中选择“保存并退出服务”。

三个包的默认数据目录分别是 `%LOCALAPPDATA%/HyperEvolution/Enlighter/data`、`%LOCALAPPDATA%/HyperEvolution/Evolver/data` 和 `%LOCALAPPDATA%/HyperEvolution/Self-Evolver/data`。实际位置可在设置中查看。旧超维成长用户可以通过 `--data` 继续使用原目录；请先在原版本创建加密恢复包。

升级时退出旧服务，再解压新程序。数据目录单独保存。换电脑前，在设置里创建加密恢复包，保管好密码，然后在尚未设置身份的新实例恢复。

## 常见问题

**没有弹出页面：** 再双击启动文件，或在程序目录打开终端，运行 `.runtime\Scripts\python.exe -m growth_local --edition self` 查看启动信息；将 `self` 换成对应版本，并先设置 `PYTHONPATH=src`。反馈问题前先隐去口令、密钥和学习者信息。

**测试 API 失败：** 核对接口地址、模型名、余额和 Key 权限，再确认电脑能够访问服务商。

**收不到老师的任务：** 双方保持本机程序在线，查看连接状态，再检查是否选中了相同学科。连接服务设置见 [网络教程](network.md)。

**想在同机演示师生：** 分别启动教师包和学生包。它们使用不同目录，可在两个浏览器页面配对。
