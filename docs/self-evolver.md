# Self-Evolver · 自学版

从一份短资料和一个具体问题开始，先走完一次学习。

## 第一轮：阅读、练习、反馈与复习

1. 解压自学包，双击 `启动-Self-Evolver.cmd`，确认自主学习身份。
2. 配置自己的模型 API，点击测试连接并保存。
3. 在“学科与路线”选中学习领域；到“读资料与提问”导入自己有权使用的文字或图片，并写清来源。
4. 先读一小段，提出具体问题，例如：“这一段为什么先讲例子，再讲结论？”资料解释会围绕已选来源展开。
5. 进入“练习与作品”，写明目标，选择合适的方法和评价标准，预览后开始。
6. 提交一次实际作品，在“反馈与复习”获取 AI 建议，回到原文核对，修改自己的回答。
7. 写下这次最需要改进的一点，安排下一次复习，再用不同材料练一次。

## 一个容易上手的例子

导入一小段介绍校园花园的英文材料。目标设为“用一个理由说明花园对学生的帮助”，完成一段三到四句的回答。查看反馈后，检查理由是否有来源、解释是否清楚，再修改一次。下一次换成图书馆或运动场的材料继续练习。

## AI 的作用

资料解释帮助你理解当前内容；练习草稿帮助你开始行动；作品反馈帮助你寻找修改方向。模型使用本机设置里的 API Key，额度属于你自己的服务商账户。

自学反馈、本人反思和复习记录分别保存。你可以回看原稿与修改稿，自己调整下一次安排。

## 日常入口

自学首页、读资料与提问、练习与作品、反馈与复习、目标与安排。需要老师带学时，可以切到 Evolver，配对后完成老师的任务。

详细操作见工作台“使用指南”或[完整自学说明](usage/self-study.txt)。安装与备份见 [开始使用](getting-started.md)，外部 Agent 接入见 [MCP](mcp.md)。
