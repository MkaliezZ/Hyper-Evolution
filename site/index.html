YOUR MODEL, YOUR ACCOUNT

API 怎么填，谁的额度？

打开安装后的本机工作台，在“连接与设置 → 模型与本机设置”配置。准备好服务商控制台提供的四项信息。

要填什么怎么找到
服务商选择你的模型服务，或使用支持相应能力的 OpenAI 兼容接口。
API 基础地址按服务商文档填写。例如 DeepSeek 预设使用 https://api.deepseek.com；兼容服务通常会给出以 /v1 结尾的地址。
模型名称复制服务商控制台提供的准确模型标识。图片提问时，选择支持图片输入的模型。
API Key使用你自己创建的 Key。选择记住后，Windows 版本保存在系统凭据管理器；也可以只在本次使用。
网页内置 AI

使用本机填写的 API。

资料解释、练习草稿、写作建议、自学反馈、教师 AI 预审，都使用当前用户自己的模型配置。测试连接也会发送一次小请求，费用来自该服务商账户。

老师的 AI 预审使用老师的额度；学生自己的 AI 帮助使用学生的额度。

外部 AGENT + MCP

使用 Agent 自己的模型。

外部 Agent 通过本地 MCP 读写允许访问的学习工作区，模型推理使用该 Agent 自己配置的服务。网页和 Agent 共享本机学习记录。

调用云端模型时，完成本次任务所需的材料和作品会发送给你选择的模型服务商。

CONNECT YOUR OWN AGENT

让自己的 Agent 接上本地 MCP。

先打开学生版本机工作台，在“模型与本机设置”复制本机生成的 MCP 配置，粘贴到自己的 Agent 中。

  1. 先完成本机身份设置，在“连接与设置 → 模型与本机设置”找到“查看本地 MCP 连接配置”。
  2. 复制完整配置，粘贴到支持 MCP 的 Agent 的设置中。配置包含本机 Python 入口、源码位置和当前数据目录。
  3. 重新连接 MCP，让 Agent 先读取本机身份与当前学科，再交代具体任务。

A FEW USEFUL ANSWERS

卡住时，从这里继续。

第一次打开为什么要等？

启动包先准备 Python 和所需依赖，会访问 GitHub 与 Python 包源。保持联网和启动窗口打开，等待完成后浏览器会自动出现。网络中断时，恢复连接后再次运行启动文件。后续启动直接使用本机环境。

配对码怎么用？

老师在教师版生成十二位配对码，学生在学生版的“我的老师”输入。配对码十分钟有效，过期由老师重新生成。双方保持程序在线，连接成功后选中相应学科收发任务、作品和反馈。自学版可以直接开始；需要老师带学时切到 Evolver 再配对。

API 测试没有通过，先检查什么？

依次核对基础地址、准确模型名、Key 权限、余额及网络。更换接口地址时，重新输入对应的 Key，再测试并保存。连接问题可附版本、步骤和已隐去密钥的报错提交给测试组织者。

MCP 连接后看不到我的任务？

回到你实际使用的工作台，重新复制本机生成的 MCP 配置，检查它指向正确的程序和数据目录。重新连接后，让 Agent 读取当前身份与学科；教师、学生和自学版分别使用各自的默认目录。

教师 AI 预审之后怎么发给学生？

教师在“作业与反馈”打开实际提交，运行 AI 预审，逐项修改建议并保存草稿。检查完成后，明确确认发布，学生就能收到教师反馈。学生根据反馈修订后，再次提交。

关网页、退出服务、升级和换电脑分别怎么做？

关闭网页后，本机服务会继续运行。准备退出或升级时，在设置里选择“保存并退出服务”。升级前先创建加密恢复包，再解压新程序。学习记录保存在用户目录，具体位置可在设置查看。换电脑时用恢复包和自己保管的密码恢复到新实例。

学习记录在哪里？需要官网账号吗？

本机版本从身份向导开始使用，学习记录保存在用户电脑。师生明确分享的任务、作品和反馈会在双方设备保存副本。连接服务负责协商与必要中转；云模型收到的是完成所选任务所需的上下文。
